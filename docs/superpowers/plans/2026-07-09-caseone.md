# CASEONE Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and release CASEONE — a Wix-hosted headless site where users "design" custom iPhone cases in a simulated AI studio, preview them on a 3D phone, and buy via Wix checkout.

**Architecture:** Managed Wix Headless (Astro 5, auto-auth — no OAuth client in app code). Wix backend: Stores (1 product, model×finish variants), CMS (`styles`/`designs`/`gallery` collections), Forms (inquiry). Frontend: static-first Astro pages + React islands (3D preview, studio, cart badge). All "AI generation" is deterministic selection from the seeded `designs` collection behind `src/lib/generateDesigns.ts`.

**Tech Stack:** Astro 5 + `@wix/astro` (scaffolded via `npm create @wix/new@latest -- headless`), React islands, three.js, `@wix/data`, `@wix/stores`, `@wix/ecom`, `@wix/redirects`, Wix REST (seeding via `curl` + minted CLI token).

## Global Constraints

- **Astro 5 only** (scaffold pins it; never upgrade to 6 — astro.md A1).
- **No OAuth client in app code** — managed-Astro auto-auth: `import { x } from "@wix/<pkg>"` directly (astro.md §2, A7, A8).
- **Always `npm install --ignore-scripts`** — never diagnose/retry `sharp` failures (astro.md A9).
- **`astro.config.mjs` must keep `wix()` + `wixPages()` + `react()` and `security: { checkOrigin: false }`** (astro.md A2).
- **Guard every SSR SDK call in try/catch**; islands reading browser state are `client:only="react"` (A3, A4). No HTML comments in `.astro` frontmatter (A5).
- **Resolve `wix:image://` URIs with `media.getScaledToFillImageUrl`** from `@wix/sdk` — never hand-build CDN URLs (A6).
- **Release once, at the very end** (Task 15). No mid-flow build+release; no dev-server smoke loops (CREATE.md §5).
- **Token: mint once** per run via `npx @wix/cli@latest token --site "$SITE_ID"`, cache in `seed-artifacts/` env file; never re-mint as a recovery step.
- **Brand tokens:** canvas `#FAF8F5`, coral `#FF5A47` (primary CTA), teal `#1FB6A6` (secondary), ink `#17151F`; headings Space Grotesk, body Inter; 24px radius; all motion behind `prefers-reduced-motion`.
- **Copy anchors (verbatim):** tagline "Design the only iPhone case in the world that looks exactly like you"; stats "From idea to case in 60 seconds", "No templates. No duplicates. Your case is generated for you.", "Spin it before you buy it".
- **Commerce:** product "CASEONE Custom Case", $59 base, Leather finish $79; options "iPhone Model" = [iPhone 15, iPhone 15 Pro, iPhone 16, iPhone 16 Pro, iPhone 16 Pro Max], "Finish" = [Matte, Glossy, Leather].
- **12 style slugs (canonical, everywhere):** `cyberpunk, minimal-luxury, anime, streetwear, marble, floral, abstract, graffiti, vintage, y2k, futuristic, photo-collage`.
- **Seed artifacts** (IDs produced by seeding, consumed by the frontend) are written to `<project>/seed-artifacts/*.json` — exact shapes defined per task below.
- Accessibility: semantic landmarks, labeled controls, keyboard path for the 3D viewer and studio, AA contrast.
- No parameterized detail routes are planned → the item-page SEO wiring (astro.md §6) is **not needed**; main pages get managed SEO automatically.
